## 🌌 Ringkasan Proyek (Executive Summary)

> *"Saat telemetri wahana antariksa jutaan kilometer mendadak hening di balik kegelapan gerhana asteroid, para insinyur antariksa tidak menebak-nebak — mereka menginvestigasi bukti, membuktikan akar masalah, dan merancang ulang masa depan penerbangan."*

**ORBITA NOVA: The Last Telemetry** adalah game simulasi investigasi forensik dan rekayasa sistem antariksa yang dikembangkan oleh **Team Certified Space Cap** untuk **NASA Space Apps Challenge 2026**.

Game ini mengedepankan pendekatan **Educational-First & Balanced Simulation**: menghubungkan prinsip-prinsip nyata fisika penerbangan antariksa NASA dengan gameplay interaktif yang adiktif, taktis, dan bebas dari kebiasaan "AI slop". Pemain bertindak sebagai penyelidik forensik yang membedah kegagalan satelit ASTER-9 dan wahana antariksa antardimensi lainnya melalui standar 5 tahap metode ilmiah.

## 🔄 Core Gameplay Loop (Standar 5 Tahap Forensik)

Seluruh misi utama (*Story Mode*) dirancang mengikuti disiplin investigasi resmi:

```
  ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
  │ 1. INVESTIGATE  │ ──> │   2. ANALYZE    │ ──> │   3. DESIGN     │
  │ Briefing & Data │     │ Hypothesis Proof│     │  Modular Refit  │
  └─────────────────┘     └─────────────────┘     └─────────────────┘
                                                           │
                          ┌─────────────────┐              ▼
                          │    5. LEARN     │     ┌─────────────────┐
                          │ Orbit Sim & KPs │ <── │   4. EXECUTE    │
                          └─────────────────┘     │ Rewind & Crisis │
                                                  └─────────────────┘
```

1. **INVESTIGATE (Temukan Masalah)**:
   - Mendengarkan audio kokpit/telemetri CVR (*Cockpit Voice Recorder*) dan data sensor DOR.
   - Menelusuri grafik telemetri 4-kanal (*Bus Voltage, Solar Output, Battery SOC & Temperature, Power Draw*).
   - Menandai (*pinning*) anomali fisik sebagai bukti forensik.
2. **ANALYZE (Pahami Penyebab)**:
   - Menghubungkan bukti ke dalam **Hypothesis Matrix**.
   - Evaluasi berjenjang oleh dewan investigasi (*Correct, Partial, Incorrect*) untuk membuktikan akar masalah kegagalan.
3. **DESIGN (Rancang Solusi)**:
   - Merancang ulang wahana di **Modular Satellite Hangar**.
   - Memilih Panel Surya (GaAs vs Silikon), Baterai (*Cold-Resistant*), Termal (*Active Heaters* vs MLI pasif), dan Antena (*High-Gain* vs *Laser DSOC*).
   - Terikat batasan nyata: Pagu Anggaran **\$120M** dan Batas Massa Roket **450 kg**.
4. **EXECUTE (Jalankan Misi)**:
   - **Crisis Rewind Mode**: Mengubah keputusan saat genting sebelum satelit mati mendadak (*UVLO shutdown*).
   - Mengoperasikan mini-game perbaikan teknis (*Cable Connection, Power Grid Routing, Antenna Gimbal Alignment*).
5. **LEARN (Evaluasi Hasil)**:
   - Menjalankan simulasi orbit 3D dengan Three.js melintasi bayangan gerhana asteroid (*Umbra*).
   - Debriefing edukasi dengan visualisasi 5 Pilar Sistem NASA, evaluasi *Ghost Replay*, dan kartu prestasi *What You Learned*.

## 🏛️ ORBITA NOVA Academy (Pusat Belajar Antariksa)

Academy dirancang agar pemain dapat mempelajari konsep antariksa kapan saja tanpa harus menunggu misi selesai:
- **6 Modul Pembelajaran Mandiri** sesuai topik Episode 01–06.
- **Mission Insight**: Penjelasan teori dan terminologi sains antariksa yang ringkas dan padat.
- **Visual Learning**: Diagram skematik subsistem teknis interaktif.
- **Practical Scenario**: Simulasi penggeser (*slider*) parameter fisik mikro (misal: sudut panel surya vs watt terpanen, atau lapisan MLI vs suhu inti).
- **Knowledge Check Quiz**: Kuis evaluasi pemahaman berhadiah **+25 Knowledge Points (KP)**.
- **Sistem Pangkat Misi**:
  $$\text{Kadet Antariksa} \longrightarrow \text{Insinyur Sistem} \longrightarrow \text{Analis Senior} \longrightarrow \text{Direktur Misi}$$

## 🛡️ Arsitektur Keamanan Tinggi & Backend Database

Proyek telah dipisahkan menjadi `Game-Frontend` dan `Game-Backend` dengan standar keamanan siber enterprise:

- **Database Mesin**: Menggunakan SQLite native Node.js 22+ (`node:sqlite`) dengan journaling *Write-Ahead Logging* (WAL) dan jaminan transaksi ACID penuh. Tersimpan persisten di `Game-Backend/data/orbita.db`.
- **Kriptografi Scrypt**: Hash kata sandi memory-hard dengan garam (*salt*) acak kriptografis 32-byte ($N=16384, r=8, p=1, \text{keyLen}=64$). Kebal terhadap serangan brute-force GPU dan ASIC.
- **Perlindungan Timing Attack**: Verifikasi hash dalam waktu konstan $O(1)$ dengan `crypto.timingSafeEqual`.
- **Sliding-Window Rate Limiting**: Mengunci IP/akun selama 15 menit jika gagal 5 kali berturut-turut untuk mencegah serangan tebak kata sandi.
- **Google OAuth Single Sign-On (SSO)**: Kemudahan masuk menggunakan akun Google secara instan dan aman.
- **Post-Login Callsign NOVA**: Setelah otentikasi pertama, maskot NOVA menyapa pemain untuk mengambil nama panggilan (*Callsign*) yang disinkronkan ke database dan dipakai sepanjang permainan.

## 💻 Panduan Instalasi & Menjalankan Lokal

### Prasyarat
- **Node.js**: Versi `22.0.0` atau lebih tinggi (dibutuhkan untuk native `node:sqlite`).
- **NPM**: Versi `10.0.0` atau lebih tinggi.

### 1. Menjalankan Frontend
```bash
# Masuk ke direktori frontend
cd Game-Frontend

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```
Buka browser di `http://localhost:5173`.

### 2. Menjalankan Backend Server (Opsional untuk Database Terpusat)
```bash
# Masuk ke direktori backend
cd Game-Backend

# Install dependensi
npm install

# Jalankan server backend
npm run dev
```
Backend akan aktif di `http://localhost:3001` dengan database SQLite otomatis dibuat di `Game-Backend/data/orbita.db`.

### 3. Build Produksi
```bash
# Build Frontend
cd Game-Frontend
npm run build

# Build Backend
cd Game-Backend
npm run build
```

## 🌐 Panduan Deployment (Online Hosting)

### Opsi A: Deploy Frontend ke Vercel (100% Gratis & Instan)
1. Push repositori ini ke GitHub Anda.
2. Buka [Vercel.com](https://vercel.com) dan klik **Add New Project**.
3. Import repositori Anda:
   - **Root Directory**: `Game-Frontend`
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Klik **Deploy**. Web game akan langsung aktif dan bisa dimainkan di URL `.vercel.app`.

### Opsi B: Deploy Backend ke Railway / Render
1. Buat project baru di [Railway.app](https://railway.app) atau [Render.com](https://render.com).
2. Pilih direktori `Game-Backend`.
3. Start command: `node dist/server.js` (atau `npm start`).
4. Dapatkan domain API publik untuk disematkan pada konfigurasi frontend.
